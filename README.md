# Shivers Racing Labs — Public Documentation

Independent motorsport technology, race instrumentation and technical education.

This repository contains the informational SRL website, the F1 Hidden Tech product overview, and draft legal documentation. Bot software is maintained separately and is not included here.

## Website M1

- index.html — SRL headquarters and project overview
- hidden-tech.html — F1 Hidden Tech product preview
- privacy.html — draft privacy policy
- terms.html — draft terms of service
- style.css — responsive carbon/red and cyan design system
- REVIEW.md — release checklist

No JavaScript, external fonts, analytics scripts, forms or paid services are needed. The brand image is the public GitHub organization avatar. The product wordmark is an original text treatment for this site.

## Publishing

After review, configure GitHub Pages to deploy from main / (root). No deployment is configured by this branch. Use HTTPS and verify links before adding policy URLs to the Discord application. This site is informational, not a storefront or SaaS host.

Draft policies are not effective and must be reconciled with actual hosting, retention and support procedures before use.
